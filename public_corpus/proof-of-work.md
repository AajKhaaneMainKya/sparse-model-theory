# Proof Of Work

Public proof in this repository includes a FastAPI backend, browser UI, SQLite session persistence, deterministic note routing, semantic retrieval tests, structured planner output, OpenAI-compatible model calls, Ollama-compatible fallback, thread summaries, and an OpenClaw agent endpoint.

The work emphasizes ambiguity handling: confirming scope before analysis, stating missing information, separating claims from evidence, detecting gaps, and avoiding fabricated conclusions when inputs are incomplete.

Evidence of agentic systems includes a planning pass, gap detection pass, optional follow-up pass, synthesis pass, and explicit controls for thinking depth and skipped skills.
